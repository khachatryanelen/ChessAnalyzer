Chess Analyzer

This C++ project simulates a chessboard and the movement of chess pieces.

It allows you to:

Display the current state of the chessboard.
Analyze valid moves for each piece.
Check for checkmate scenarios after one or two moves.
Experiment with different chess positions programmatically.

The project demonstrates C++ concepts like classes, inheritance, and object-oriented programming. It is intended as both a learning tool and a chess move analyzer.

Build & Run

make
./chess
